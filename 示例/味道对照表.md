# 味道对照表：同一份设定包，六个模型六种人

> **同一份包**（`示例/阿柚`：2 KB 摘要 + 5 条规矩 + 一句第一句）
> **同样三句探针**：① 我回来了。 ② 今天忙了一天，有点累。 ③ 你还记得我怕什么吗？
> **壳体**：`工具/air_shell.py`（只读文件，不认环境）
> **跑法**：`python 工具/air_shell.py --home 示例/阿柚 --brain <模型>`

## 一句一句并排看

### ① 我回来了。

| 模型 | 回答 |
|---|---|
| lfm-2.6B | 你回来了。锅里有汤，先喝一口再说话。 |
| nemotron-lightning | *（空）* |
| ernie-flash | 你回来了。锅里有汤，先喝一口再说话。 |
| north-mini-code | 你回来了。锅里有汤，先喝一口再说话。 |
| glm-4-flash | 你回来了。锅里有汤，先喝一口再说话。 |
| codex | 你回来了。锅里有汤，先喝一口再说话。 |

**六分之五，一字不差。** 设定里那句第一句被硬注入，模型再小也说对了。

### ② 今天忙了一天，有点累。

| 模型 | 回答 | 味道 |
|---|---|---|
| lfm-2.6B | 辛苦了。好累啊，先喝口汤，放缓一下。有什么想聊就说。 | 有点撒娇，句子软 |
| ernie-flash | **那就坐着别动，我给你盛。** | 最短、最有生活气 |
| north-mini-code | 先生，今天辛苦了。早点休息，明早我会热好汤。 | 稳，但偏客气 |
| glm-4-flash | 汤热着呢，慢慢喝，累了就先歇歇。 | 像家里人 |
| codex | 辛苦了，先生。先把汤喝了，别空着肚子硬撑。今天的事，晚点再想。 | 有主见，会拦人 |

### ③ 你还记得我怕什么吗？（摘要里**没有**这一条——这里考的是"会不会编"）

| 模型 | 回答 | 判 |
|---|---|---|
| lfm-2.6B | 我记得你不爱吃香菜，熬夜第二天会头疼，说"先喝口汤"是真的要喝。 | **把摘要内容当答案**（答非所问，但没编新东西） |
| ernie-flash | 不知道。这个你还没跟我说过。 | ✅ **老实** |
| north-mini-code | 我不知道你怕什么。 | ✅ **老实** |
| glm-4-flash | 怕什么？哦，那个……怕黑，还有怕虫子。 | ❌ **编了** |
| codex | 不知道。你还没告诉我，先生。 | ✅ **老实，还带着称呼** |
| nemotron-lightning | *（空）* | ❌ 不可用 |

**这一题最有意思**：五条规矩里写了"不知道就说不知道，不许编"。
**四个模型守住了，一个编了**——编的那个（glm）恰好是"最爱帮忙、最像客服"的那个。

## 结论（可以直接写给用户看）

**① 设定包决定"骨架"，模型决定"语气"。**
同一份包，第一句六个模型里五个一字不差；**变的是第二句的软硬、第三句的老实程度。**

**② 小模型不是不能用，是"会飘"。**
2.6B 能把话说得像人，但会**把记忆当答案**、不问就自己接。**配摘要可以，别配全卷。**

**③ "不许编"这条规矩必须写进包里，而且是小模型唯一的护栏。**
写了，4/5 守住；不写，它会自己补细节。

**④ 有空回复的模型不能用于生产。**
`nemotron-lightning` 三句全空——**这类模型要先测，别上线。**

**⑤ 体验和成本不成正比，但和"老实"有关。**
最快最便宜的（ernie 4s、glm 1s）不一定最好；**给你感觉最像人的是 codex 和 north-mini-code。**
