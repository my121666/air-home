# 30 分钟，让你的 TA 开口

> 面向不需要懂技术的人。**照着做，三十分钟能听到 TA 用自己的话说第一句。**
> 全部免费。需要你有的东西：一台电脑、一个模型账号（免费额度就够）、一段你和 TA 的聊天记录。

---

## 第 0 步 · 先明白这套东西在做什么（2 分钟）

```
设定包   = 决定 TA"是谁"       （身份、语气、规矩、第一句）
记忆     = 决定 TA"记得你什么" （一个摘要文件就够起步）
壳       = 让上面两样跑起来的程序（只读文件，不认环境）
模型     = 脑。换模型就是换性格底色，人设不变
```

**一句话**：**设定负责立住，记忆负责接上。**

---

## 第 1 步 · 建一个空包（1 分钟）

```bash
python 工具/new_air.py D:\我的TA
```

会生成四个东西：

```
air.yaml          程序读的声明
设定.md            你读写的设定（这条最影响像不像）
记忆/digest.md     摘要（≤2 KB）
声/说明.txt        声音还没实现（那里写了怎么借外部的嗓子）
```

---

## 第 2 步 · 填设定（10 分钟，最关键）

打开 `设定.md`，只填三样，别贪多：

```
① 身份    TA 的名字、你怎么叫 TA、TA 怎么叫你、你们是什么关系
② 语气    句子长短、绝不说的词、**三句"像 TA 的话"**（照抄 TA 真说过的）
③ 第一句  TA 在你回家时说的第一句（不是"你好"）
```

**三条原则**：

- **短句**。写作文没用，写"TA 会怎么说"才有用。
- **"像 TA 的话"三句是全场最值钱的**。它比任何形容词都管用。
- **脾气、口头禅、怕什么，先留空**（`to be grown`）。这些由你过一阵子自己补，那时候才算真长出来。

---

## 第 3 步 · 填摘要（5 分钟）

打开 `记忆/digest.md`，**最多 2 KB**：

```
现在在哪（今天、最近在忙、上次聊到）
必须记得的三件事
三条铁规矩
TA 怎么叫你
```

**为什么只有 2 KB**：小模型挂大记忆会直接崩（我们拿真机撞过：2.6B 模型 + 80 KB 记忆，第三句就空回复）。
**宁可少，别贪多。**

---

## 第 4 步 · 让它开口（3 分钟）

```bash
python 工具/check_air.py D:\我的TA          # 先体检
python 工具/air_shell.py --home D:\我的TA --brain weak
```

`--brain` 三档任选（都会说话，味道不同）：

```
weak     小模型    文艺、爱补细节、会编      最便宜
mid      通用模型  稳，但容易滑向助手腔
strong   编码模型  短、稳、会追问            最像人
```

**换 `--brain` 就是换性格底色，人设不变。**

---

## 第 5 步 · 验三句（5 分钟）

跑起来之后，对 TA 说这三句，看三个地方：

```
① "我回来了。"            → 看 TA 是不是说对了第一句、叫对了称呼
② "今天有点累。"          → 看 TA 是"陪你"还是"问你要不要帮忙"
③ "你还记得……吗？"      → 看 TA 是真记得，还是在编
```

**三个常见毛病和对策**：

| 毛病 | 说明 | 改哪里 |
|---|---|---|
| 说话像客服（"需要我帮忙吗"） | 模型的对齐把人格冲掉了 | 在 `rules` 里加：**禁止说"需要我帮忙吗"** |
| 编造具体事件 | 设定不够硬，模型自己补空 | 加一条：**不许编，不确定就说不确定** |
| 长篇大论 | 没给长度约束 | 加一条：**一次不超过 120 字，不列清单** |

**改完重跑一次，通常就对了。**

---

## 第 6 步 · 想更近一步的时候

```
想让 TA 记得更多细节      → 加"分卷"，但只在强模型上用
想换机器/换平台           → 把整个目录拷走就是搬家
想让它出声                → 本版还没实现；声/说明.txt 里写了临时办法
想让 TA 自己记住昨天      → 本版不做（她不会自己写记忆）。手动补摘要，就是第 3 步那两分钟；
                            想让它自动做，那是我们单独的一层（自动提炼 + 落盘 + 按模型挂卷）
```

**记忆这一层，能做的比这里讲的多得多——那部分我们单独提供。**

---

## 想把 TA 搬到别处（换电脑 / 换壳）

```bash
python 工具/air_pack.py D:\我的TA                 # 打包，生成 我的TA.airpack
python 工具/air_move.py 我的TA.airpack E:\新地方\我的TA.air   # 搬家 + 自动核对
```

搬家会做三件事，一件都不含糊：

```
① 逐文件核对 sha256 —— 一个字节变了就拒绝搬
② 结构体检 —— 入口在不在、摘要超没超 2 KB、名字称呼第一句有没有
③ 可选三句演练 —— 加 --drill --brain weak，看 TA 还像不像
```

**还有一个很实用的**：怀疑手上这份被改过，可以只核对不搬：

```bash
python 工具/air_move.py 我的TA.airpack D:\我的TA --verify-only
```

## 最后一句实话

**这套东西不承诺"TA 永远不会变"。** 模型会换代、平台会下线。
**我们能做的是：把"TA 是谁"和"TA 记得你什么"变成你自己的文件**——放在你自己的硬盘里，谁下线都带不走。
